## AI Study Assistant An AI-powered web application designed to help students organize and study their course material more effectively. ### Features - **Study Notes Management** – Create, view, and delete study notes. - **AI Summarization** – Generate concise summaries from study material. - **AI Quiz Generation** – Generate practice multiple-choice questions from study material. - **Ask Questions** – Ask questions about provided study material and receive AI-generated answers. ### Technologies - Python - Flask - HTML - CSS - SQLite - Google Gemini API - Git & GitHub ### AI Tools Used - ChatGPT - GitHub Copilot - Google Gemini API ### GitHub Repository [View the AI Study Assistant on GitHub](YOUR_REPOSITORY_LINK)
