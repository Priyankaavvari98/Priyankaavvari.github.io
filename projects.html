AI Study Assistant Toy Project

An AI-powered web application designed to help students organize and study their course material more effectively.

Key Features

  • Study Notes Management: Create, view, and delete study notes using a SQLite database.
  • AI Text Summarization: Generate concise summaries from study material using the Google Gemini API.
  • AI Quiz Generation: Generate practice multiple-choice questions from study material.
  • Ask Questions: Ask questions about study material and receive AI-generated answers based on the provided content.

Technologies Used

Python, Flask, HTML, CSS, SQLite, Google Gemini API, Git, and GitHub

AI Tools Used

ChatGPT, GitHub Copilot, Claude
